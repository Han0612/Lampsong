# CATLIGHT06 v106 · 验收记录

## 本轮范围

- 保持投影现有清晰度与采样预算；取消不同形状新旧投影的 55 ms 交叉淡化，每次只显示一个已完成轮廓。垂直投影渐隐与歌词切换渐隐不受此修改影响。
- 猫咪上沿退场为向前下方转身、蓄力、下跳；其他图集增加帧间形变，尾巴增加随时间变化的位移。素材一览与主场景共用处理。
- 加入 PH 5、Caravaggio、Concert、GUBI 1965、GUBI A1965、Romeo Soft、Mayfair、Jazz、Flamingo、Skan、Disco。保留原七款。
- 灯体使用缓存轮廓与分层材质；浅色 GUBI 无上方金属配件。Disco 镜面球连续旋转，背景彩斑缓慢扫动，标签为 special。
- 灯具选择两列九行，不滚动。悬停预览不保存，点击才选择。
- 封套背面与侧边采用封面取色的暗色渐变，独立于灯光魔法色开关。
- 字体菜单隐藏四款，清刻本保留，黑体和宋体集中排列。42 MiB 完整字体目录无修改。旧字体预设映射到保留的相近字体，不丢弃其他设置。

## 已验证

- 投影：连续形变输出不包含旧轮廓混合；过期位图关闭、后台队列有界、故障可回退。现有分辨率、渐隐及投影几何回归通过。
- 同一四行中英文绘制测试（2 行实体 + 2 行纯影，180 次）：v105 暖绘 P95 22.5 ms，v106 7.8 ms；两次均后台正常、4 行已就绪、0 待处理。此为云端绘制调用耗时，不能等同于用户设备整页 FPS。
- 猫动画：27 份形变数据、向下退场轨迹、连续帧与支撑脚位置、blob 资源键、缓存限制回归通过。单猫局部绘制 P95 4.6 ms，后台补帧 P95 7.0 ms；同样不代表整场景 FPS。
- 灯具：18 个注册 key、18 个卡片、两种模式预设可用；新灯具不叠加旧的通用发光底座。
- 浏览器：正常主界面、纯影/实体切换、清刻本加载、Disco 色斑、封套翻转、灯具菜单操作通过。
- 面板：桌面两列九行，scrollHeight 等于 clientHeight；320×568 和 740×390 视口均无裁切、无滚动。
- 保留系统默认参数服务与管理校验。没有改写云端系统参数、密码或访问权限。

## 用户验收

1. 拨动灯具，观察两种模式投影是否不再出现双轮廓过渡。
2. 唤猫与猫素材一览：观察转身、尾巴、上沿下跳；确认实际设备不卡顿。
3. 打开灯具面板：18 款全部看见；检查新材质、浅色 GUBI、Disco。
4. 翻转封面：背面为暗色渐变，切封面后颜色跟随。
5. 字体菜单：四项隐藏、清刻本保留、类别顺序整齐。

当前为工程检查与云端浏览器验证，不代表用户视觉验收已完成。
