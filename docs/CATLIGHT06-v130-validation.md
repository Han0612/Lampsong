# CATLIGHT06 v130

## 本次范围
修复满亮度光心发灰；排查迪斯科多层光源是否影响普通灯。不修改灯型分布、猫素材、歌词渲染/清晰度、用户歌词、已保存系统默认值或访问范围。

## 诊断与改动
- v129 把主光先压入 8 位，再乘空间衰减；即使纹理峰值255，静止空间系数0.85也会把它压到约217。颜色压缩不能解决此亮度上限。
- 主光新增480×640半曝光缓存，两次加法绘制保留亮度余量，在空间衰减之后才裁切。亮度100%、原1.20增益不变。高亮允许接近白色，外围分布保持原逻辑。
- 原参考纹理保留给微弱副光束和关灯余光。副光束仍限迪斯科；普通灯无副光源叠加。主光先绘制，再叠迪斯科副光，不扩大猫的判定光区。
- 全部灯的节奏系数统一在光照、材质和光斑合成后应用一次，保留v113节奏波形，避免新增高亮余量吞掉节拍变化。歌词及字影仍在节奏合成之后绘制。
- 摇晃不重新生成纹理，不增加逐帧模糊、画布分配或曝光交叉渐变。额外固定缓存像素与画布约2.5MB。

## 验证
- light-highlight-color：真实Canvas执行当前/旧版buildLight与帧光照片段，加载实际地面材质。三种颜色×经典半球/暗红浅穹/现代薄碟的光心平均RGB峰值：雾青约203→243–244，米白约214→255，灰紫约204→250–251。暗部平均差低于1.8/255。检查45/100亮度响应、121步连续空间衰减及零次摇晃重烘焙。
- 已人工查看隔离光照的v129/v130渲染图：高亮核心恢复，原外围衰减保留。这些是无歌词/灯体的Canvas测试图，不是完整浏览器截图。
- disco-rhythm-composite：81个实际层合成节奏对比、5个换灯混合权重；迪斯科切回普通灯像素与直接显示普通灯一致，无副光束/光斑/混合状态残留。球体节奏、前景顺序通过。
- rhythm-v113：27种节拍、对比度、刷新频率组合的节奏系数与旧版完全一致，开关平滑、静音回到基准。
- rest-visibility、scene-rest、light-profiles、floating-fade（2016组合）、floating-controls、system-defaults、pure-lyric-centering通过。
- npm run build，JS语法，git diff --check通过。
- 原生Canvas单次测量（640×420，90帧，仅光照，无像素读回）：普通灯约0.40→0.70ms，迪斯科约2.03→1.82ms。此为本机测试，存在测量波动，不是浏览器FPS，也不承诺实际设备性能。
