# CATLIGHT06 · v105 验收记录

2026-11-05。沿用当前节点。

## 本次改动

- 两种歌词模式均采用独立后台变形队列，光照遮挡计算继续使用已有后台队列。动画帧只合成缓存图像；同一行最多一个在途批次，后续更新取最新位置，不堆积旧帧。
- 使用单像素连续扫描和亚像素横向采样，取消原来的双像素台阶与半像素扩散量取整。稳定背板尺寸，上下位置/长度持续更新；明显形变短暂融合，小于采样像素的变化直接复用。
- 原字体掩模、投影分辨率预算、字号、透视角、接触点、渐隐/柔化数值保持原来的计算关系。无 Worker/OffscreenCanvas 时保留普通 Canvas 兼容路径。
- 控制台、灯具菜单、指南、管理弹窗与提示加入可打断的淡入淡出。hover 反馈约180ms，菜单200ms，控制台220ms。减少动态效果偏好下即时切换。
- 猫素材一览展示27份完整动画：12组A/B，共24份，加3组退场。独立播放/暂停、重播、逐帧滑杆、纯黑/原色切换。只播放可视区域，释放较久不在屏幕中的已解码图集。
- 修复自动预览把24/32/40帧素材截为16帧的问题；根据实际图集尺寸确定帧数。

## 验证

- 投影采样/原始字形、渐隐与角度关系、后台缓存、最新任务优先、失败回退及资源释放测试通过。
- 逐行推移、自动换行、灯距上边界/下边界独立、系统参数、猫姿态、沉浸模式测试通过。
- 菜单连续开关/取消旧退出回调/关闭即移除输入权限检查通过。
- 浏览器检查两种模式、拨灯、下一行、控制台反复开关、指南开启关闭、猫素材预览与末帧。
- 27份源图集均可读取；帧数16/24/32/40按实际尺寸核验。

## 性能边界

同一云端浏览器四行中英文、180次动态绘制，v104稳定段P95约24.1ms，本次约19.2ms（约减少20%），无后台失败或移动触发的重复光照计算。这是绘制压力样本，不代表完整页面帧率，也不代表用户设备表现。未依赖WebGL硬件加速。

仍需用户设备验收：纯影长拖影斜边、连续摇灯、最大字号/极长拖影、多行及高DPI显示屏的清晰度和流畅度。未在物理手机上测试。
