# v111 上沿反向弧线跳走

保留 v110 清晰 16 姿态和其他原图集。上沿离场在正面姿态处完成左右转向，起跳朝进入方向的反侧；每个完整原画以其体心注册，避免切朝向时位置突跳。

时序：0.68s 转身、0.28s 蓄力、0.16s 蹬离；起跳水平速度为屏高的 0.35/s，竖直初速度 -0.38 屏高/s，重力 1.4 屏高/s²。约 0.271s 到最高点，再加速落下至完全出画。画廊与主场景复用同一轨迹及镜像方向。

测试：左右方向 × 三种尺寸的六组轨迹验证反向、先上后下、向下加速度、无水平瞬移、16原生姿态全使用、完整出画。26其他图集及原生画帧渲染不变。

视觉限制：仍使用16张独立原画，不使用光流或变形补帧；转向通过正面姿态切换镜像，需场景视觉验收其衔接。
