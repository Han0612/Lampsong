# CATLIGHT06 v126 — 悬浮投影修复

## 改动
- 基础模糊与渐变模糊扩大有效范围。Canvas 滤镜通过实际像素检测才启用；不支持时使用三遍可分离 alpha 模糊。灯光运动仍复用缓存，不生成过渡重影。
- 渐变模糊、渐隐各自增加 0–360° 方向，0° 向下、90° 向右、180° 向上、270° 向左。起点/范围按实际字形边界计算，与透明补边无关。
- 投影不透明度独立整行显示：0% 无投影，100% 最浓；不改字面。
- 模式入口统一为「投影、立体、悬浮」。管理员摘要同步。
- 悬浮字色为深墨色、浅魔法色、柔白色、自定义。浅魔法色以 RGB 243 为亮度基准，加入封面明度差的 10%，限制在 232–251；独立平滑跟随封面，不受灯光魔法色开关或 Disco 色彩循环替代。
- 两个角度支持个人预设、刷新恢复、JSON、管理员默认及旧设置补值。

## 已验证
- floating-controls.cjs：24 项控件；实际 alpha 扩散与中心软化；原生滤镜及强制无滤镜兼容路径；90°/270° 的反向模糊和渐隐；0/50/100 不透明度；浅魔法色亮度和饱和度范围；缓存不随灯运动重算。
- system-defaults.cjs：新角度随模式切换及刷新保留。
- defaults-api.mjs：新角度保存、隔离、迁移和既有权限校验（测试存储，不写线上默认）。
- pure-lyric-centering.cjs：旧投影像素、边界与缓存回归通过。
- JS 语法、diff 检查、82 参数服务端构建通过。
- Chrome 预览：基础模糊 0/100 的轮廓变化；不透明度 0 隐藏影子并保留字面；角度 36°/72° 独立调节及刷新保留；模式入口和浅魔法色选项可见。
