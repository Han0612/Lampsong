# CATLIGHT06 v106 cat motion

- New upper departure artwork: `art-source/cat-exits/upper-jump-v106.png`, generated by built-in image generation on 2026-11-05 using `dist/cat-stills/dangle.png` as identity/style reference. Sixteen frames: side crouch → front three-quarter pivot → gather hind legs → jump downward; no rear-facing walk. Transparent RGBA preserved when packing the 4×4 runtime WebP.
- Final prompt: same dark plum fluffy kitten, exact 4×4 transparent sprite sheet, consistent scale, readable front-facing turn, then natural downward jump, front paws reaching down and tail counterbalancing; no scenery, text or ledge.
- Existing 26 motion sheets remain byte-identical. All 27 sheets now have offline measured forward/backward motion vectors, generated by `scripts/measure-cat-flow.py` (OpenCV, Pillow and NumPy build-time only). This is geometry metadata, not a repaint of the art.
- Runtime `cat-motion-smooth.js` / `cat-motion-worker.js` samples six positions per authored interval. A single nearest drawing is inverse warped; two differently positioned images are never opacity-blended. The tail has a small delayed displacement that falls to zero before the hip.
- Playback trajectories preserve fractional frame positions; support-paw height interpolates with the drawings. Upper departure uses a gravity-driven downward trajectory and waits for the entire visible silhouette to leave the viewport.
- Worker source atlases are downsampled to 288×192 per cell, original transferred bitmaps are immediately closed, and only four cells per source retain pixel arrays. Main scene holds at most three sources; gallery at most eight. Only visible gallery cards request frames. Latest requests supersede queued intermediate requests.
- Blob-backed preloads carry an explicit `catMotionKey`; smoothing does not depend on reading a filename from the blob URL.
- Without Worker/OffscreenCanvas support, original authored keyframes remain available. Reduced-motion mode uses static authored poses.

Validation: `node tests/cat-motion-continuity.cjs`, `node tests/cat-random.cjs`.
The temporary `qa-cat-motion.html` can measure complete main-thread cat shadow draws and worker synthesis cost; exclude it from deployment.

Cloud-browser cost check (single cat, 60 timed samples, first 15 warmup): complete main-thread cat shadow draw P95 **4.6 ms**, worker geometric frame synthesis P95 **7.0 ms**. Old 16-sample cat shadow path measured 13.8 ms P95 before reducing its aperture sampling to 8 and raster floor to .24. This is a local draw-cost check, not full-scene or device FPS. Cloud rAF was background-throttled (around 1 second) and is not a usable animation-rate measurement.
