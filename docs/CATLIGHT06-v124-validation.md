# CATLIGHT06 · v124 验收清单

- 新增悬浮歌词模式：立体字面、厚度与墙上短投影；三个独立数值滑杆。灯具光照继续共用，排版与宠物等继续按模式保存。
- Cmd+S / Ctrl+S 导出当前场景 PNG，自动排除全部界面、封面面板、文字、歌词及字影，保留灯、光、猫、微尘及昆虫。截图与显示复用同一帧前景，不额外推进动画。
- 重绘蜷卧 24 帧与侧卧 16 帧；起身沿匹配姿态反向播放，熟睡时轻微呼吸。点猫播放短段回应，不出现实体手影。
- 猫大小使用原生猫的统一尺寸基准，同次出场保持随机百分位，实时响应最小/最大比例设置。
- 更新柔和米白手型鼠标。保留 0.5 秒长按动作面板、选动作后不收起、只有 X 收起。
- 更新睡猫素材一览与玩法指南。
