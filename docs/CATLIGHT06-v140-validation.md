# CATLIGHT06 v140 · 共享播放行为

2026-11-10。延续 CATLIGHT06，基于已发布 v139（7d95514f06479396e15d0928c7d392d376e8bd1a）。用户已确认开始。

## 改动

- 三种模式共用：逐字动效开关、随音乐节奏、逐字速度、自动换句、自动换行、换行动画类型、换行动画速度。
- 仍独立保存：上浮幅度、影响范围、起落柔和度、排版、字面明度/不透明度、投影及宠物参数。
- 浮字与投影的旧开关/速度字段统一归一化，旧会话以最后使用模式为准，避免切回模式时恢复旧开关。自动换行和切换动画由旧独立localStorage键兼容迁移。
- 自动换行、切换动画类型纳入完整预设及服务器校验。JSON导入和恢复默认会应用共享播放设置，保留其他模式视觉参数。
- 最新管理员保存作为三模式共享播放默认，按读取时合并，不覆写其他模式原始默认文档。管理员保存说明同步更新。
- 底部逐字开关与控制台双向同步；不修改歌词渲染和灯光效果。
