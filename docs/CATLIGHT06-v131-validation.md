# CATLIGHT06 v131

## 改动清单
1. 关灯改为固定的微弱环境余光：大范围、低亮度、中性偏冷的场景照明，按窗口坐标分布。去掉灯口主光、副光、光斑和所有歌词投影；灯体与歌词勉强可见。灯光亮度、颜色、摇摆及节奏不驱动余光。
2. 关灯后继续使用原有两轴重力/阻尼引擎，不瞬移归零。取消音乐与环境风驱动，保留现有角度和速度，自然回摆归位；微小余振收敛后停算。
3. 恢复关灯后的拖动、点击/键盘轻推、松手惯性。每次绘制更新灯具命中位置，电线随灯连接。关闭手动发光高亮，灯体材质先完整合成再统一降低亮度，避免素材内部透明度覆盖暗场设定。
4. 歌词、猫、灰尘/昆虫、灯球旋转及自动光照仍暂停。环境场景缓存；灯具用有界画布单独绘制，停止后复用整帧。开灯恢复正常场景；休眠时间不累计到猫的闲置/唤醒计时。
5. 窗口缩放会重新构建静态环境；隐藏页面时释放拖动并暂停灯具积分，回来后不补算离开期间的时间。截图仍保存当前实际画面。
