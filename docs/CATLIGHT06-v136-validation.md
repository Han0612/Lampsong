# CATLIGHT06 v136 · 2026-11-10

## 改动
- 关灯时迪斯科镜球保留当前角速度，按1.1秒阻尼时间常数减速，约3.3秒衰减95%，随后缓慢收尾到静止。开灯接续当前角度；自动/手动旋转选项不被关灯修改。隐藏窗口暂停，减少动态偏好仍生效。
- 投影模式增加轻微伸展/回收的逐字波浪，根部固定；立体字面逐字轻抬，邻字按距离减弱，投影随波峰变化。悬浮沿用v135连续波浪。
- 三模式独立保存逐字开关、幅度、速度、两侧范围与柔和度。新增模式默认开启、幅度4%、速度100%、范围3字、柔和度70%；范围沿用0–18%、50–180%、1–6字、0–100%。旧设置补齐，不改管理员文档。
- 沿用原始投影缓存，先合成原有接触层，再对整行投影做一次波形变换；整数列合成消除直接分段multiply绘制的接缝。关闭、首尾归位保持原渲染像素。固定字号与字距，不重排。

## 验证
- projected-wave：240帧中英文、两种模式；首尾像素相同、冻结时相同、字面大小固定、预热后无新增ray bake或canvas分配；不整除纹理宽度无透明接缝。
- 性能：本地Canvas相同长英文立体测试从初稿约64ms/帧降至约18ms/帧。原静态路径约8ms/帧，因此新动效仍有开销。浏览器软件渲染环境里旧路径也较慢，不能以此保证用户机器60fps；真实设备流畅度需验收。
- disco-power-coast：30/60/120Hz惯性距离一致，速度单调衰减到零，开灯接续相位、隐藏暂停与减少动态通过。scene-rest实际关灯分支继续调用coast。
- system-defaults：投影/立体开关与幅度/范围相互独立并跨刷新保留；悬浮参数保持。defaults-api管理验证及旧数据迁移通过。
- floating-wave 1200帧与27组波峰参数、2016组floating-fade、floating-controls、visual-row-navigation、pure-lyric-centering、rest-visibility、rest-lamp-physics、rest-window-motion、disco-auto-motion、disco-controls回归通过。
- 浏览器：确认两种模式设置、投影4%与立体8%/范围4字独立保存及刷新恢复；检查波浪/投影画面、关灯微光与再次开灯，随后恢复逐字4%/3字及自动转速。截图：docs/qa/CATLIGHT06-v136-wave-settings.png。
