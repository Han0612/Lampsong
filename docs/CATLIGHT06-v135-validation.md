# CATLIGHT06 v135 · 2026-11-10

## 改动
- 悬浮逐字动画改为一个持续推进的波峰；当前字最高，两侧邻字按距离降低，不再使用各字独立的时间脉冲。波峰从行前移入、行后移出，五次缓动起止与紧支撑钟形轮廓保证平滑回位。
- 设置统一命名「逐字动效」：保留开关、上浮幅度0–18%（7%）、速度50–180%（100%）；新增影响范围1–6字（两侧各约3字）、起落柔和度0–100%（70%）。越柔和，邻字起落越舒展；任何档位均保持平滑边缘。
- 保持字面原始像素、字号、字距、换行及视觉行切换。沿用影子同步位移/柔化和整行渐隐合成。旧预设自动补齐新增值；独立模式设置与管理员保存规则保持。
- 仅修改悬浮动效；不改灯光、猫、字体资源、用户歌词、云端默认文档、密码或访问范围。继续CATLIGHT06。
