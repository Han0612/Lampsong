# CATLIGHT06 v119 验收

2026-11-06，北京时间；继续更新当前节点。

## 改动

- Disco主光、副光、接收面纹理和彩斑完成叠加后，再统一应用原有节奏明暗系数。普通灯原有绘制链路保持；灯型渐变期间连续过渡，歌词、字影与前景不受额外全局压暗。
- 球体GPU材质与Canvas降级材质都在最终颜色阶段响应整组节奏，保持不透明镜片、体积与反射层次。修复球面星芒未遵守灯体预览淡入淡出透明度。
- 保留所有灯共用的节奏识别、对比参数、平滑速度和亮度基准；没有单独加深Disco节奏，也没有改变光束、光斑形态及自动旋转。
- 保留开启节奏灯光且播放时临时取消30%亮度折扣、关闭恢复的逻辑。
- 复用当前画布，仅增加一次灯光合成后的平涂；无新全屏缓冲、无逐帧像素读回、无新增模糊计算。

## 验证

新增实际Canvas像素回归：使用生产光照分布、真实接收面纹理、56个生产彩斑和球体软件材质；固定姿态，对照明暗帧。

- 3个旋转角度 × 3个彩斑强度 × 3个节奏系数，共27组像素检查。
- 亮度系数1时，光束和彩斑与v118逐像素相同；普通灯在0.78/0.9/1系数下与v118逐像素相同。
- 输入下降10%时，测试画面旧链路最终平均下降8.06%，改后9.80%；与目标差异为8位合成量化误差。确认原来是变化被削弱，并非完全没有收到节奏信号。
- 每个通道与整体乘相同节奏系数的理论结果误差不超过1.2/255，均值比例误差小于0.6个百分点。
- 球体软件材质全反射响应、前景绘制顺序、原有自动旋转/保存/模式切换等回归通过。
- 全部tests/*.cjs、defaults-api.mjs、构建和diff检查通过；57项服务端校验不变。

限制：Canvas离线像素验证已完成；实际浏览器WebGL、听音和帧率仍待实机验收。未绕过此前浏览器访问策略限制。
