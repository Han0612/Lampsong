# CATLIGHT06 v138 · 2026-11-10

## 改动
- 底部歌词控制面板在「自动换句」右侧增加「逐字动效」，保持一行与统一控件高度。复用当前模式的 floatWave / projectedWave，不新增重复的持久化开关。点击底栏通过现有 input 事件更新控制台与保存逻辑；设置、模式切换、恢复默认、预设应用同步更新底栏。
- 纯投影波浪的宽竖条原先按中心采样、整条平移，条边的位移跳跃造成台阶锯齿。改为相邻条共用端点、条内连续垂直仿射插值。固定纵向比例，不加模糊、不重叠 alpha、不交叉渐隐，也不提高贴图分辨率或分段数量；重置画布变换避免污染后续帧。立体与悬浮保持原路径。

## 验证
- projected-wave-edges：641/1365/2048 宽度及三个波峰位置，共九组实际 Canvas 像素测试。相对连续目标曲线的位移 RMS 从旧方法 0.371px 降至 0.042px；各列 alpha 总量、厚度不变，无接缝或重复叠加。
- projected-wave：240 帧中英文与两种模式，归位像素一致、冻结一致、预热后无新 bake/Canvas，向上空间不裁切，非整除列宽无漏光。
- 性能：原生 Canvas 同进程交替测量旧/新波浪合成 160 个有效帧，新方法约增加 4.7% 耗时；整行字影场景测得纯影约 10–11ms/帧。不同测例、字体和环境的绝对耗时不可直接横比，不作真实设备 60fps 保证。
- system-defaults、console-interactions、visual-row-navigation、lyric-tempo、rest-visibility 全部通过。构建仍为 93 项服务端参数，没有增加另一份开关设置。
- 浏览器：底栏关掉投影波浪后控制台同步关闭，切立体仍开启，切回投影保留关闭；控制台开启后底栏同步开启。悬浮关闭后刷新仍关闭。1363×936 下底栏宽 317px、高 48px，四个控件同高 36px、同一行对齐。查看了运行时的投影画面。应用未报告错误，浏览器扩展有元数据通信错误。
