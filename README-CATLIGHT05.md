# CATLIGHT05 · 微光

保存日期：2026-11-04。包含完整网页源码、猫影 A/B 动画与退场素材、字体、专辑封面、试听音频、节点说明及回归检查。

## 启动

先解压整个 ZIP，不要在压缩包内直接打开。

- Mac：双击 `Start-Mac.command`。如终端未执行，可在终端进入该目录运行 `sh Start-Mac.command`。
- Windows：双击 `Start-Windows.bat`。
- 需要 Python 3；无第三方 Python 依赖。也可用现有静态服务器将 `dist` 作为根目录。
- 启动后自动打开浏览器；服务只绑定本机 127.0.0.1。关闭终端或按 Ctrl+C 停止。
- 不要直接双击 `dist/index.html`，浏览器的 file 协议会限制素材读取。

网页、猫影、封面、字体、五首试听素材均已打包，可断网运行。素材来源和授权网页链接仍需联网访问。

## 操作与参数

拖动灯具，点击右下角猫爪或按 C / 空格唤猫。氛围设置里可以指定单个动作核对，随机模式避免连续同一动作。两种歌词模式分别保存设置。

本地版使用新的浏览器地址，线上 localStorage 不会自动迁移。若要保留自己线上调节的参数，请在两个模式中分别导出 JSON，再在本地对应模式导入。包内默认值是当前源码默认值，未包含浏览器私人存储数据。

## 本节点变化

F 隐藏全部控件、封面和 UI 文字；再按 F 或 Esc 恢复。输入框中输入 F 不触发。隐藏期间仍可按 C / 空格唤猫，灯光和歌词继续运行。

继承上一节点：

全部十二动作先确定左右，再在所选一侧筛选位置；每个动作按左右成对打乱，A/B 计为同一个动作进行去重。听声、拍高、洗脸收好姿势后向下缩回，不再转身走路。侧边和顶部保留各自退场动作。

`checkpoints/CATLIGHT05.json` 是节点说明；`dist` 是可直接部署的静态网站。`art-source` 保存新增退场原图；`scripts`、`tests` 为素材处理及代码检查。运行测试：`node tests/cat-random.cjs`。

本节点更新：空格优先唤猫（文字输入除外），唤猫按钮上移18像素；右下角小字号半透明 Powered by Arthursun。此为换灯前的基准版本，保留原有四款灯型。
