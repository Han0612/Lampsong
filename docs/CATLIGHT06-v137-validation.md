# CATLIGHT06 v137 · 2026-11-10

## 改动
- 投影逐字波浪从向下伸展改为向上轻抬、复位；邻字按距离渐弱，沿用平滑起落曲线。合成列不再改变高度，保留向上空间防裁切。立体和悬浮原有字面/投影处理保留。
- 三模式新增独立「随音乐」开关，默认开启。用试听 BPM 与实际音频重拍包络平滑调速；连续积分相位，调速、暂停或开关跟随不直接重算波峰位置。没有播放时平滑回到速度滑杆设定。减少动态偏好继续生效。这是动效模拟，不是逐字演唱时间轴；本地音源的节拍强弱来自实时分析，BPM 使用现有试听节拍参考。
- 从主页面完全卸下 CatCompanion / SleepingCat、睡眠空闲调度、抚摸、唤醒及退出流程；删除睡眠按钮、设置、手型光标和指南内容。保留睡猫源文件、素材及独立核对页，后台不再预加载其图片。原有 CatPaw 十二动作、短按随机、0.5 秒长按、选动作后固定展开直到 X 关闭均保留。
- 旧个人/管理员设置里的 catIdleSleep 不再生效；读取时剔除旧字段，补齐逐字设置，未覆写管理员保存的原文档。
- 指南精简为两列八项：拨灯、换灯/开关灯、三种歌词、封面音乐、节奏色彩、唤猫、设置、纯净与截图。修正旧版关灯隐藏投影的过时说明。
