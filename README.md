# 灯下词 · Lampsong

灯下词是一款在浏览器里运行的歌词光影互动作品。拖动吊灯再松手，灯和字影会带着惯性一起摇晃。换一张唱片封面，灯光可以从封面取色，背景也会随之过渡。这个版本基于 CATLIGHT06 v148。

## 在本地打开

- Windows 安装 Python 3 后双击 `Start-Windows.bat`。
- macOS 安装 Python 3 后双击 `Start-Mac.command`，也可以运行 `python3 offline/serve.py`。
- 使用 Node.js 22 或更新版本时，可以运行 `node scripts/preview.mjs`，再访问 `http://localhost:4173`。

Python 启动器默认打开 `http://127.0.0.1:8840`。两种本地预览方式都可以直接使用包内素材，无需安装 npm 依赖。

## 玩法

- **歌词**有投影、立体和悬浮三种模式。投影只显示字影，立体同时显示字面和拖影，悬浮让字面离墙并投下柔影。控制台可调字体、排版和逐字起伏，也可以粘贴自定义歌词。
- **灯与唱片**可切换十二种灯具，包括能旋转、打出彩色光斑的迪斯科镜球。点击封面可以翻面，换封面可以改变灯色和虚化背景。
- **音乐**可试听五段内置音乐，也可以播放本地音频。音乐可以驱动灯光和逐字起伏，换行由设定的时间间隔控制。
- **猫与截图**可点击猫爪随机召唤剪影猫，长按可从十二种动作中挑选。按 `F` 进入纯净模式，按 `Esc` 返回。`Ctrl+S` 或 `⌘S` 可将画面保存为 PNG。
- **预设**可将三种模式的参数一起导出或导入。个人设置保存在当前浏览器，本地预览自带默认参数。

## 项目结构

| 位置 | 内容 |
| --- | --- |
| [`dist/`](dist/) | 可直接阅读的 HTML、CSS 和 JavaScript 源码，以及字体、封面、音频、材质和猫咪动画 |
| [`dist/app.js`](dist/app.js)、[`dist/caster.js`](dist/caster.js) | 逐帧合成场景，计算字形排版、透视和柔影 |
| [`worker/`](worker/)、[`netlify/`](netlify/) | 保存三种模式的系统默认值与各封面的默认歌词 |
| [`scripts/`](scripts/)、[`tests/`](tests/) | 本地预览、部署构建与回归检查 |
| [`docs/`](docs/)、[`checkpoints/`](checkpoints/) | 设计记录、历史验证和版本节点 |

本地预览提供完整的前端体验。保存共享默认值需要配置后端，详见 [本地开发说明](README-LOCAL.md)。试听音乐、封面和字体的来源说明可在网页控制台的「素材来源」中查看。
