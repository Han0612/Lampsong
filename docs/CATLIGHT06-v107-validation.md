# CATLIGHT06 v107 · 验收记录

## 本轮改动

- 原有七款保留；新增款仅 PH5、Caravaggio、GUBI Semi、Jazz、Disco，共12款。四款普通灯按官方资料校准比例，改用独立写实透明材质资产；GUBI按最后确认改哑光暖白，Caravaggio为黑色高光漆/釉面般反射。灯光魔法色、模式独立参数保留。素材是参考厂家资料生成的重构，不是官方照片或工程模型，见 refined-lamps-v107.md。
- Disco 使用实时旋转的三维平面镜片网格，WebGL优先；无WebGL时使用同一反射逻辑的Canvas三维兼容渲染。可见直径约64场景像素，体量比常见原灯略大；独立闪光、稀疏反射光束、彩虹光斑，保持银色镜面。反射光斑与球体共用角度，旋转镜面以双角度映射反射方向。
- Disco 专属旋转开关、速度5–100%、光斑强度0–100%；选中其他款时隐藏。首页“节奏灯光”后有同步图标和悬停提示。暂停保留角度，光斑不再自行转动，环境/节奏明暗仍生效。设置沿用服务端保存及模式预设。
- 选择面板两列六行，无滚动；选中圆点在灯左侧，灯下迷你光束，没有选中框；special紧跟名称并居中对齐；两列中线白色5%透明度。
- 去掉所有封面原生/自定义悬停提示和翻面悬停文字，保留无障碍名称与翻面、拖动交互。
- 歌词取消低分辨率临时投影，完整行集合准备后原子替换；等待期间保留上一组完整画面，不混入备用字体或新旧行。快速输入丢弃过时排队请求；提前准备后续三行。细节像素和柔化计算预算保持不变。灯光运动的形变在后台完成，初次形变也使用完整精度；滑杆手势期间直接对完整场执行几何变换。
- 猫咪全27组连续轮廓重建、关键帧注册及缓存防过期处理；移除8层离散猫影叠加，改连续高斯半影。图集原文件保持不变，详见 CATLIGHT06-v107-cat-quality.md。
- 管理密码按用户最后指示更新到服务端秘密，随本次部署生效；秘密值不写入代码、节点文档或前端。

## 验证

21项回归通过：projection-presentation、projection-animation-cache、projection-resolution、projection-surfaces、shadow-fade-and-fan、visual-row-navigation、lyric-layout-and-throw、lyric-boundaries、lamp-styles、lamp-perspective、light-profiles、disco-controls、system-defaults、console-interactions、ui-motion、clean-mode、cat-random、cat-motion-continuity、cat-motion-quality、cat-motion-cache、defaults-api。

- 原子呈现测试验证：首屏不显示草稿；新行仅完成一部分时仍显示整组旧行；字体重载不复活旧缓存；快速滑杆请求不会堆积。已有分辨率/柔化像素与几何测试保留。
- 云端浏览器检查纯影/实体两模式、切封面、调透视和渐隐、白色GUBI、写实灯具、Disco选择、旋转开关双向同步、滑杆边界、控制项隐藏和封面提示清零。
- 12卡片面板scrollHeight=clientHeight=329；选中background透明、box-shadow:none；中线rgba(255,255,255,.05)。
- 云端两行纯影微基准最终后台路径：主线程drawRows中位0.1ms / P95 0.3ms；冷启动两行最终场约0.66秒（期间保留完整旧画面）。冷启动包含后台计算和调度，不能代表所有设备；滑杆触发新的柔化场也可能有短暂等待。直接几何绘制路径约7.3ms中位，取决于字宽和行数。以上为局部调用耗时，不是整页FPS。
- 云端WebGL不可用，因此浏览器验证的是三维Canvas兼容路径；镜球局部绘制约3–4.4ms中位，尾部开销受并行预览影响。GPU路径代码已检查，硬件视觉/帧率需实机验收。
- 猫咪592区间像素检查通过；浏览器猫影主线程P95 6.6ms、worker15.3ms，不等于FPS。细透明胡须和绒毛可能略柔化。
- 完整字体目录未更改。应用没有新增运行错误（云端浏览器扩展metadata日志排除）。构建、语法和diff检查通过。临时QA页不发布。
