# CATLIGHT06 v139 · 行间层次与切换速度

2026-11-10，继续当前节点；基于已发布 v138（bacc58842607c5a84dc5308deff19edfc2a7f6ed）。用户已确认本批开始。未更改用户设置的行数。

## 改动与验收

- 歌词排版增加同一行左右排列的“当前行 / 其他行”参数。投影为不透明度0–100%；立体、悬浮为字面明度0–200%（100%原色，低于100%压暗，高于100%提亮），字面仍不透明，原有投影透明度和渐隐继续独立。
- 默认：投影100/70；立体100/130（深色字时其他行提亮）；悬浮100/70。切换当前行平滑交接。旧预设仅补充缺失项，不重写管理员原文档。
- 纯影强调字号此前连字间距一起横向放大。现在以普通行字号作为字距参考，仅重映射缓存投影中的间隔；原始字形与射线烘焙复用。换行测量同步使用修正后宽度。
- 歌词切换内新增速度50–200%，100%保持1.2秒，50%为2.4秒，200%为0.6秒；同时作用于逐行推移和整屏渐隐。自动换行/逐字音乐速度使用原时钟。
- 全部新增参数按投影、立体、悬浮分别保存；支持个人设置、JSON及管理员默认值服务。灯光、字体、猫素材及用户歌词未改。

- 120帧字号变化不增加射线烘焙或Canvas分配；本环境原生CPU光栅测得约16.5ms/帧，不代表用户设备或整页GPU帧率。悬浮明度120帧复用材质画布。
